Saving

HexSeal saves on its own; there's no save button.

  • It saves every few seconds whenever something has changed.
  • It saves when you leave the app, travel, sleep, or touch a waystone.
  • Saves are written safely, so a crash can't corrupt your game.

Saves are kept on your phone. See the privacy policy for what that means for your data.

Save slots

You can keep up to five saves. Tap Saves on the title screen to see them all, each with its name, character level, region, play time and when you last played.

  • Play loads that save.
  • Rename gives it a name of your choice.
  • Delete removes it, after asking first.

New Game always uses an empty slot. It only asks to replace a save when all five are full.

If you played before save slots arrived, your save moved into slot 1 on its own, and a backup was kept.

Moving or backing up a save

You can copy any save to a file and open it on another iPhone or iPad.

To export: open Saves, then tap Export on a slot. The share sheet opens, so you can AirDrop the file, send it in Messages or Mail, or save it to Files. The file is called something like Ash (slot 1).hexhold, and a copy also stays in Files › On My iPhone › HexSeal › Exports.

To import: put the .hexhold file in the HexSeal folder in the Files app (On My iPhone › HexSeal), then open the game. The title screen asks whether to load it into an empty slot or replace one. Replacing asks first, keeps a copy of the old save, and never offers the save you're playing.

If you tap Not now, ×, or Back, the file moves to Files › On My iPhone › HexSeal › Declined. Nothing is deleted and the game won't ask about it again. To import it later, put it back in the HexSeal folder. If the question closes without an answer, it comes back after a few minutes.

  • A damaged file is refused, so it can't break your game.
  • Exported saves are sealed. A file that's been edited outside HexSeal is refused with "This save was changed outside HexSeal."
  • Files exported before build 200 need exporting again from the latest version.
  • A save from a newer build asks you to update HexSeal first.
  • Nothing is sent to a server. The file only goes where you send it.

Don't delete anything in the saves folder inside the HexSeal folder. That's where the game keeps your slots.
